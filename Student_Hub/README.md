# Student Hub - Dynamic Submission

## Flow
1. Open `index.html` for the information/landing page.
2. Use Login or Register.
3. Login redirects to `deskboard.html`.
4. Use the hamburger menu to navigate all modules.

## Requirements demonstrated
- Dynamic UI: FAQ, modal, slider, notification banner, hamburger menu, light/dark mode
- JavaScript DOM selection/manipulation
- Event handling
- localStorage theme persistence and demo login state
- CSS transitions and responsive layout
- Accessibility labels, ARIA states, keyboard-friendly controls
- Registration validation with HTML5 attributes + JavaScript + regex
- Password strength meter
- JSON: events.json, students.json, faqs.json (15 records each)
- Fetch API
- Dynamic rendering
- Search, filter, sorting and pagination
- Loading/error handling
- Shared modular shell.js and app.js

## Fetch API note
For Fetch API JSON loading, run the folder using a local server (for example VS Code Live Server). Opening the HTML directly with `file://` can block fetch requests in some browsers.
